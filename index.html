About

I'm a freelance software developer in Zimbabwe. I build websites and web platforms for businesses, schools and non-profits, and I'm most at home on Java and Spring Boot backends, where accuracy matters more than anything else.

My day-to-day covers new backend features, financial reports in JasperReports, database work, build and deployment pipelines, and security hardening. Before software engineering became my main focus, I studied data science and still reach for Python, Pandas and Scikit-learn when a problem is about data.
